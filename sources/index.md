# Source index

This project preserves five primary source groups:

- [Humalike documentation corpus](./docs/source.md): discovery indexes, the consolidated documentation export, and 29 individually fetched pages.
- [HUMA paper source](./papers/arXiv-2511.17315v1/source.md): LaTeX, bibliography, and included figures.
- [LoSoNA paper source](./papers/arXiv-2606.14600v1/source.md): LaTeX, bibliography, and included figures.
- [Hermes Humalike plugin source](./hermes-humalike-plugin/source.md): the public client plugin implementation and tests.
- [Live API observations](./live/source.md): redacted request/response records captured against the production API.

Distilled findings live in [research](../research/index.md), while the rebuild contract lives in the [specification](../spec/00-index.md).
